# Custom Hotkeys

按自己的习惯调整《要塞：十字军东征》的操作。从游戏默认、现代 RTS 或网格布局开始，重新分配键盘和鼠标按键，并将不同布局保存为配置。网格键位会随当前打开的建造或单位面板变化，让同一按键在不同面板中执行不同操作。

在主菜单或暂停菜单中打开 **选项 > 自定义快捷键**，也可以在游戏中按 **F12**。选中一项操作后按 **Enter**，再按想要使用的键或鼠标按键；按 **Delete** 清除绑定，按 **应用** 保存配置。镜头位置、编组、建筑放置和单位命令也都可以在这里设置。
